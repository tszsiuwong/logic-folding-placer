![Displacement Histogram](../figures/gcd_disp_hist.png)

### 距离-位移相关性

**r = 0.919**（极强正相关）。离 2D 中心越远的单元，位移越大——面积压缩效应主导，非 placement 策略差异。

![Correlation](../figures/gcd_disp_corr.png)

单元整体向原点收缩。2D die 面积 44.61×40.79 µm，3D 每 Die 31.54×28.84 µm——边角单元被拉回。

## 四、HPWL 对比与收益来源

> **背景**：在 [logic-folding-geometry](https://github.com/tszsiuwong/logic-folding-geometry) 中，我们曾用完全图（p=1）推导 3D 折叠的几何上界：双 Die 堆叠可节省约 17% 总曼哈顿线长。本次实验用真实布局器在真实网表（p=0.698）上检验。

2D die = 44.61×40.79 µm (1819 µm²)，利用率 23.6%。3D 每 Die = 31.54×28.84 µm (909 µm²)，总 1819 µm²，上/下 Die 利用率 23.1%/24.1%，总利用率 23.6%。

![2D vs 3D](../figures/gcd_2d_vs_3d.png)

| | HPWL (µm) |
|---|---|
| 2D | **3500** |
| 3D | **2765** |
| 3D / 2D | **79%（省 21%）** |

**收益数字一致（21% vs geometry 的 17%），但机制不同。**

由第三节的位移分析可知：r=0.919 的位移-距离相关性、dx=−29/dy=−26 的方向偏差、同/跨 Die 邻居 2D 距离完全相同——这三个证据共同指向同一个结论：**placer 的层指派近乎随机，HPWL 下降来自面积压缩而非垂直折叠。** geometry 的 17% 是 p=1 理想值下的折叠收益；gcd 实测 p=0.698，placer 没有利用垂直维度，收益来自密度优势。

| | geometry 预测 | 实测 |
|---|---|---|
| HPWL 收益 | 17% | 21% — 方向一致 |
| 收益来源 | 垂直折叠替代长线（d₂≥5） | **平面压缩** |
| 证据 | — | r=0.919; dx=−29, dy=−26; 同/跨 Die 距相同 |

### 网线级拆解

| | 网线数 | 占比 | 2D HPWL | 3D HPWL | 3D/2D |
|---|---|---|---|---|---|
| Die0 内 | 53 | 20% | 470 µm | 335 µm | 71% |
| Die1 内 | 23 | 9% | 130 µm | 98 µm | 76% |
| **跨 Die** | **189** | **71%** | **2899 µm** | **2332 µm** | **80%** |

跨 Die 网线在 2D 中平均 15.3 µm，Die 内 7.9 µm——**placer 确实优先把长线切成跨 Die（长 1.9 倍）**。但 3D/2D 比值三个类别接近（71-80%），说明**收益是全局压缩，不是选择性长线折叠**。长线切到跨 Die 后，缩短比例并不比 Die 内短线更高。

## 六、对 Agent 的启示

1. **tier 标注优先级**：总线信号 > 模块边界 >> 匿名逻辑
2. **3D 省 21% HPWL**：同面积自然密度下成立，但收益来自压缩而非折叠
3. **placer 不保留 2D 空间邻近性**：Agent 必须通过 partition 硬约束控制层指派
4. **面积压缩（r=0.919）是位移主因**：不是 placement 策略
