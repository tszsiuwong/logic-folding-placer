## 三、收益来源

> **背景**：在 [logic-folding-geometry](https://github.com/tszsiuwong/logic-folding-geometry) 中，我们曾用完全图（p=1）推导 3D 折叠的几何上界：双 Die 堆叠可节省约 17% 总曼哈顿线长。本次实验用真实布局器在真实网表（p=0.698）上检验。

2D die = 44.61×40.79 µm (1819 µm²)，利用率 27%。3D 每 Die = 31.54×28.84 µm (909 µm²)，总 1819 µm²，上/下 Die 利用率 28%/25%，总利用率 27%。

![2D vs 3D](../figures/gcd_2d_vs_3d.png)

| | HPWL (DBU) |
|---|---|
| 2D | **7.00 M** |
| 3D | **5.53 M** |
| 3D / 2D | **79%（省 21%）** |

**收益数字一致（21% vs geometry 的 17%），但机制不同。** geometry 的 17% 来自 p=1 完全图假设下的垂直折叠替代长线；实测 placer 并没有利用垂直维度——同 Die 和跨 Die 单元在 2D 上的原始距离一样（都是 41µm），层指派近乎随机。省下的 21% HPWL 来自"多了一倍硅面积"的密度优势，即平面压缩效应，证据是 r=0.919 的位移-距离相关性和 dx=−29, dy=−26 的方向偏差。

| | geometry 预测 | 实测 |
|---|---|---|
| HPWL 收益 | 17% | 21% — 方向一致 |
| 收益来源 | 垂直折叠替代长线（d₂≥5） | **平面压缩：单元被挤到更小面积** |
| 证据 | — | r=0.919；同 Die vs 跨 Die 邻居 2D 距离完全相同 |

placer 并没有利用垂直维度做"把需要靠近的单元叠起来"。层指派近乎随机。省下的 HPWL 主要来自密度优势，而非跨层链接替代了长线。geometry 的 17% 是 p=1 理想值，gcd 实测 p=0.698——在这个互联复杂度下，placer 没有采用垂直折叠。

## 四、逐单元 2D→3D 位移分析

301 个实例在 2D 和 3D DEF 中名称完全相同，可精确对位。

### 位移分布

| 分位 | 位移 (µm) |
|------|-----:|
| min | 4.5 |
| P25 | 32.4 |
| P50 | 43.7 |
| P75 | 63.1 |
| max | 88.5 |
| mean ± σ | 47.4 ± 20.1 |

![Displacement Histogram](../figures/gcd_disp_hist.png)

### 距离-位移相关性

**r = 0.919**（极强正相关）。离 2D 中心越远的单元，位移越大——面积压缩效应主导，非 placement 策略差异。

![Correlation](../figures/gcd_disp_corr.png)

### 方向偏差

| | 均值 (µm) | 范围 |
|---|---|---|
| dx | **−29.3** | [−79, +22] |
| dy | **−26.1** | [−73, +15] |

单元整体向原点收缩。2D die 面积 44.61×40.79 µm，3D 每 Die 31.54×28.84 µm——边角单元被拉回。

### Die 间差异

| Die | 数量 | 平均位移 |
|-----|------|---------|
| Die0 | 159 | 44.6 µm |
| Die1 | 142 | 50.6 µm |

![By Die](../figures/gcd_disp_die.png)

### 位移方向向量

灰色箭头：采样 20 个单元的移动方向。蓝=Die0，橙=Die1。浅色背景点为全部 301 个单元。

![Vectors](../figures/gcd_disp_vec.png)

### 位移热力图

颜色越红，位移越大。外围单元被压缩向中心。

![Heatmap](../figures/gcd_disp_heat.png)

### 2D 邻近性与 Die 分配

| 关系 | 平均 2D 距离 |
|------|--------:|
| 分配到同 Die | 41 µm |
| 分配到不同 Die | 41 µm |

**完全相同。** placer 的层指派与 2D 空间邻近性无关——Die 分配近乎随机（除总线信号外）。

## 六、对 Agent 的启示

1. **tier 标注优先级**：总线信号 > 模块边界 >> 匿名逻辑
2. **3D 省 21% HPWL**：同面积自然密度下成立，但收益来自压缩而非折叠
3. **placer 不保留 2D 空间邻近性**：Agent 必须通过 partition 硬约束控制层指派
4. **面积压缩（r=0.919）是位移主因**：不是 placement 策略
